# Architecture

`src/` is a small ESM facade with browser pixel helpers, value constructors and typed namespace views. `scripts/expand_bindings.py` generates C++ bindings from OpenCV's Python header parser and declaration collector. It replaces the stock JS whitelist and wrapper-emission stage. `scripts/extra-bindings.cpp` supplies additional native types and adapters. The upstream hand-written Mat/geometry bindings are reused, with fixes for Point3f's third coordinate and Tracker smart pointers.

Generated wrappers preserve concrete native types. Vectors are registered recursively, enum arguments use numeric constants, smart pointers retain shared ownership, and scalar output parameters become result objects. Alternative overload families remain explicitly named when JavaScript argument count cannot select a C++ overload. Virtual base classes use RTTI downcasts.

The TypeScript emitter runs the binding registrations during linking and refuses unresolved types. `scripts/finalize-types.mjs` replaces generic JS-value declarations with the matching typed arrays, tuples, geometry values, callback interfaces and filesystem API. Private unique-symbol brands distinguish native classes while preserving their inheritance. C++ derived methods can hide incompatible base overloads; declaration inheritance uses `Omit` to model that rather than asserting nonexistent overloads.

`scripts/namespace-types.mjs` generates namespace views, inherited static factories and nested classes from the compiled declarations and parser metadata. Runtime aliases reuse the same native functions. Their declarations are derived from the exported signatures, so an alias cannot acquire a separate hand-maintained signature.

`scripts/graph-bindings.cpp` bridges typed graph nodes to G-API's native runtime argument descriptors. OpenCV allocates graph outputs, and the bridge returns the actual matrices, scalars and arrays. Drawing primitives retain their native variant types. `scripts/graph-kernels.cpp` constructs native GCall nodes and CPU kernel packages for custom matrix operations. `scripts/dnn-bindings.cpp` bridges synchronous TypeScript layers to OpenCV's CPU DNN executor. `scripts/graph-typed-kernels.cpp` adds heterogeneous custom port signatures and validates callback outputs before converting them to native values. `src/graph-types.ts` maps literal port tuples to exact node, runtime-value and metadata tuples. Callback handle tracking uses a separate native list so mutating the JavaScript argument arrays cannot prevent cleanup. The graph and DNN bridges use `scripts/callback-bridge.hpp`: callback matrices borrow shared pixel storage, temporary handles are released, and JavaScript failures become native exceptions so C++ cleanup runs.

`src/streaming.ts` implements serial pull-based scheduling over native GComputation execution. Each stream retains its computation and compile arguments. A frame's release callback runs after the graph finishes, while returned Mat headers retain their own pixel references. Stop aborts pending source reads, waits for them to settle, and closes the source. The native G-API streaming executor creates native threads and is not used by this single-threaded build.

`scripts/graph-inference.cpp` binds upstream generic inference operations and supplies a native OpenCV DNN backend. It reads tagged `GNetPackage` parameters, infers dense tensor layouts through `Net::getLayerShapes`, creates CPU kernels and delegates execution to the existing CPU graph executor. Region lists clone each forward result before DNN reuses its buffer. The backend uses the pinned private G-API backend interface, so an OpenCV upgrade requires checking it again. `applyWithMetadata` attaches signed 64-bit sequence/timestamp values to native input arguments for upstream metadata kernels. Stream release failures dispose outputs that cannot be delivered to the caller.

The declaration generator keeps native algorithm `clone` overloads intact and explicitly preserves the current handle type for inherited Embind handle cloning. This matters because TypeScript's `Omit` otherwise reduces the inherited clone return to a base handle, losing the class API.

The pinned Emscripten runtime has a local fix for inherited overload dispatch: registration only edits methods owned by the current prototype. Without this fix, registration of one ML subclass corrupts overload dispatch on sibling classes. The SVM prediction test reproduced that failure before the patch and passes with it.

OpenCV's virtual filesystem support is enabled for Emscripten. This is needed for temporary files used by codecs as well as explicit native file APIs. Emscripten's memory filesystem remains per instance; no host files are mounted.

`scripts/extract-docs.py` captures documentation from the exact pinned OpenCV and contrib headers, including unwrapped overloads that contain the main explanation. `scripts/document-types.mjs` resolves overloads, inherited comments, copy references and renamed bindings, converts Doxygen to editor-readable JSDoc, and adds package-specific descriptions and lifetime rules from `scripts/api-docs.mjs`. It audits the resulting TypeScript AST for missing comments. Namespace properties carry explicit documented aliases because key-remapped types can lose property comments in editor hovers. `lib/documentation.json` distinguishes source-backed, manual, structural and limited descriptions.

The build pins source hashes for FreeType, HarfBuzz, HDF5, Leptonica, Tesseract, gflags, glog, Ceres, Imath, OpenEXR and libdeflate in `scripts/dependencies.json`. Docker compiles their static archives before OpenCV. WASM patches disable unavailable native diagnostics, avoid x86 instruction detection in Tesseract, and require a usable Ceres dependency for SFM. The SFM camera constructor initializes its polynomial distortion fields, and reconstruction output bindings use matrix vectors to match the underlying implementation.

OpenCV 5's WASM half-float SIMD store is patched to unpack four float lanes through a float array. Upstream's double array interpreted pairs of float bits as doubles and read beyond the stored lanes. Tests cover half and bfloat conversion at SIMD and tail lengths. Matrix helpers use the OpenCV 5 channel shift and expose exact bigint views for 64-bit integer pixels. The JS binding generator also depends on every wrapped Python module so its header inventory is complete on a fresh CMake configuration.

The new ANN index uses Annoy's single-threaded build policy under Emscripten. The upstream multi-threaded policy requires native workers, which this artifact does not provide. Tests build an index and check its nearest-neighbor result in Node and Chromium.

The Python comparison captures a pinned reference wheel in a development-only Docker environment. It compares runtime names, callable kinds, constants and class methods, and records exclusions and adaptations separately. This catches missing namespaces and aliases, but execution tests remain necessary to establish behavior. The packaged runtime has no Python dependency.

The native artifact remains external to the small Vite-built facade. Consumers bundling the package pass a WASM asset URL explicitly. There is no global `cv`, network service, Python interpreter or runtime npm dependency.
