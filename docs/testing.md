# Execution tests

Version 0.0.6 exercises **69 scenarios in both Node and Chromium**, plus browser ImageData conversion, a module worker, invalid-input checks and isolated runtime loading. These are executed algorithms and file round trips, not just checks that a function exists. Every exported API has not been tested.

| Test group | Scenarios | Evidence checked |
| --- | ---: | --- |
| Core runtime | 12 | Pixel values, six codecs, feature descriptors, SVM prediction, ONNX inference, ArUco, thinning, flow, background subtraction, FLANN, UMat, geometry and native files |
| Python API additions | 5 | Graph matrices/scalars/opaque results, graph drawing, MJPEG AVI frames, factory aliases, custom DNN callback results and failure recovery |
| Native dependencies | 5 | FreeType glyph pixels, OCR output `HELLO`, HDF5 round trips, triangulated coordinates, Ceres reconstruction of 40 points and three cameras |
| Additional modules | 16 | Ten numeric Python comparisons, plus trained face recognition, saliency maps, retina output, plot pixels, CPU segmentation and text channels |
| Custom graphs and streams | 6 | Native custom kernels, multiple outputs, callback cleanup, changing frame dimensions, EOF, cancellation, concurrent pull rejection, source replacement, video sources, native sequence/timestamp metadata and disposal after release callback failures |
| Typed custom graph kernels | 5 | Mixed matrix/scalar/opaque results, all array and opaque port kinds, signed/unsigned 64-bit limits, drawing primitives, invalid output rejection and cleanup after callbacks alter argument arrays |
| Native graph inference | 12 | Six scenarios for each of ENGINE_NEW and ENGINE_CLASSIC: multi-input/output ONNX, reshaping, invalid model/input/output names, image preprocessing, regions, region lists, mixed tensor/region lists, independent output ownership and streaming retention |
| OpenCV 5 additions | 8 | New type encoding and channel limits, exact 32/64-bit integer pixels and overflow rejection, boolean storage, half/bfloat conversion, MatShape and scalar/1D tensors, finite masks, parameterized filtering, ANN feature indexing and point-cloud octree searches |

The Python numeric fixtures come from `opencv-contrib-python-headless==5.0.0.93` and NumPy 2.2.6. They cover `intensity_transform`, `img_hash`, `quality`, `ptcloud` (`depthTo3d`), `phase_unwrapping`, `structured_light`, `reg`, `xphoto`, `signal` and `shape`. Tests compare complete small outputs against Python, with a default absolute tolerance of `1e-5`; white balance permits a one-level difference in 8-bit pixels. The fixtures are generated by `scripts/python-behavior-reference.py` and contain no external model data.

Additional Python DNN fixtures check named arithmetic outputs, channel swapping with scaling and mean subtraction, and cropped-region results. The tiny ONNX fixtures are generated by `tests/fixtures/create-model.py` without downloading external weights. These compare the new graph backend with direct native Python DNN inference, not with Python's optional OpenVINO or ONNX Runtime graph backends.

Additional TypeScript fixtures use strict checking with `skipLibCheck: false`. They verify native class distinctions, typed memory views, inherited and nested APIs, synchronous callback signatures, frame source and metadata types, inference overloads and configuration, resource disposal and both handle and native algorithm cloning, and exact typed custom-kernel node and value tuples. Documentation tests check every public native declaration for JSDoc, validate parameter tags against signatures, and inspect real TypeScript editor hovers for flat APIs, namespaces, factories, ownership, graph adapters and filesystem methods.

`npm run test:package` installs the tarball into a separate directory, checks the consumer's NodeNext declarations, imports the runtime in Node, builds a Vite production application with the WASM URL as an asset, and executes graph inference, stream metadata and typed custom kernels in Chromium. It also runs typed kernels in Node and checks editor hovers against the installed package. Package verification also checks declared native exports and class members against the loaded runtime.

Run `npm test` for type, Node and Chromium checks, then `npm run test:package` for the installed consumer. `CHROMIUM_EXECUTABLE` can select a local Chrome/Chromium binary. Browsers are launched headless and muted. `bash scripts/capture-python-reference.sh` recreates the Python inventory and numeric fixtures.

These checks do not establish coverage of every overload, trained model, browser engine or maximum-size input. Firefox and Safari remain unverified. The Python inventory in `lib/python-parity.json` measures names and constants separately from these behavioral tests.
